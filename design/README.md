# Design & UI/UX Artifacts

This directory stores design assets, wireframes, and UI specifications for NeuroScript AI.

### Guidelines for Accessibility
- **ADHD Profile:** High-clarity layouts, minimal clutter, chunked flashcard workflows, clear progress markers.
- **Dyslexia Profile:** OpenDyslexic / Lexend typography, increased letter/line spacing, bionic reading accents.
- **Autism Profile:** Calm, low-saturation pastel palette, predictable navigation hierarchy, minimal jarring animations.
- **Contrast & Compliance:** Target WCAG 2.1 AA compliance across all theme variants.
